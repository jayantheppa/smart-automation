# 🚀 TestPilot – Smart Web Automation Testing Tool

TestPilot is a beginner-friendly web project designed to make website testing easier and more organized. It provides a dashboard to manage test cases, view testing activity, and generate test scenarios based on user input.

I developed this project to improve my practical knowledge of web development and software testing.

## ✨ Features

- **Interactive Dashboard** – View testing statistics and activity.
- **Test Case Management** – Create, edit, delete, search, and filter test cases.
- **Smart Test Case Generator** – Generate suggested test scenarios from a feature description.
- **Test Results** – View demo testing results and status summaries.
- **Animated UI** – Modern dark theme with a particle background and interactive visual effects.
- **Responsive Design** – Designed to work on desktop and mobile screens.

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Chart.js
- Local Storage

## ▶️ How to Run the Project

1. Download or clone this repository.
2. Open the project folder in Visual Studio Code.
3. Open `index.html` in your browser, or use the Live Server extension.
4. Explore the dashboard, manage test cases, and try the Smart Test Case Generator.

### Clone the Repository

```bash
git clone YOUR_GITHUB_REPOSITORY_URL
```

Replace `YOUR_GITHUB_REPOSITORY_URL` with your actual GitHub repository URL.

## 🧪 Current Project Status

The current version focuses on the frontend and interactive demonstration features. Test execution results are simulated, and the Smart Test Case Generator uses predefined logic to suggest scenarios. Real browser automation and backend integration are planned for future development.
